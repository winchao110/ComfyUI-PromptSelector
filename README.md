# ComfyUI-PromptSelector

七个提示词节点，一套内置词库，零依赖。 节点库搜 **taiyang**（或 `太阳`、`女性人像`、`男性人像` 等别名）就能全部找到，七个排在结果最前面。

把原先各自为战的几个提示词插件合成一个包：词库不再重复、面板外观统一、抽词节点之间互不干扰（跑男性节点不会带动女性节点换词）。原生 ComfyUI 控件收进折叠面板，画布上只留一块可交互的面板；不想要这套外观，删掉 `web/` 就退回原生控件。

---

## 一、快速开始

1. 把整个文件夹放进 `ComfyUI/custom_nodes/`（目录名保持 `ComfyUI-PromptSelector`）。
2. 重启 ComfyUI。
3. `Ctrl + F5` 强制刷新浏览器（改了前端面板 / 主题，不刷新看到的还是旧样式；节点默认是普通 ComfyUI 外观，提示词框纯黑底、按钮立体）。
4. 节点库搜索 → 敲 **taiyang**（大小写不限，由搜索别名命中）→ 拖出需要的节点。

`dependencies = []`，不需要 `pip install` 任何东西，词库随插件一起走。

> 类名保留历史命名（`Sunset*` / `ZImage*` / `Krea2*`）没有改动，所以**旧工作流可以直接加载**，不用重新连线。  
> 显示名统一用 **⚡提示词** 开头、名字里不带分类名（例如 `⚡提示词抽取`、`⚡提示词男性人像`），前缀只留这一个。

## 三、女性人像 / 男性人像（原权威摄影 / 男性摄影）

这两个是包里的重头节点，结构完全对称：**字段数相同、输出口相同**，词库整份换掉，可以直接互相替换。

| 项    | 女性人像                                  | 男性人像                                       |
| ---- | ------------------------------------- | ------------------------------------------ |
| 可调字段 | 92 项                                  | 92 项                                       |
| 词条总量 | 1862 条                                | 1818 条                                     |
| 预设   | 10 套 + 自定义组合（下拉 11 项）                 | 10 套 + 自定义组合（下拉 11 项）                      |
| 分组   | 主题 / 人物 / 妆发 / 服装 / 姿态 / 场景 / 光影 / 摄影 | 主题 / 人物 / 发型 / 服装 / 姿态 / 场景 / 光影 / 镜头 / 收尾 |
| 词库位置 | `data/lr/`                            | `data/male/`                               |
| 我的预设 | `data/lr/user_presets.json`           | `data/male/user_presets.json`              |

### 3.1 字段的三种状态

每个下拉里都混着三类特殊值，决定这一项「听谁的」：

| 取值       | 含义                               |
| -------- | -------------------------------- |
| **跟随预设** | 用预设里定好的那一个。随机范围决定它这一轮会不会被替换掉     |
| **随机抽取** | 从整个词库里随机，完全不受预设约束（不是从预设邻近的小池子里挑） |
| **不使用**  | 这一项整条不写进提示词                      |

默认全部是「跟随预设」，也就是你选哪套预设就出那套词。

### 3.2 随机范围（只管「跟随预设」的字段）

| 档位                | 保留          | 变动             | 适合          |
| ----------------- | ----------- | -------------- | ----------- |
| 局部微调（动作、表情、色彩、质感） | 主题、人物、场景、服装 | 动作、表情、色彩、质感等细节 | 同一组照片换个姿态重拍 |
| 同主题重拍（保留主题和人物）    | 主题与人物锚点     | 场景细节、镜头、光影     | 同主题换机位再来一组  |
| 跨风格混搭（全部字段）       | 无           | 全部字段           | 彻底换一套       |

字段自己选了「随机抽取」就一律全库随机，与档位无关；手选的字段永远不动。

### 3.3 提示词密度

| 密度 | 层级  | 效果         |
| -- | --- | ---------- |
| 精简 | lv1 | 只留核心项，句子短  |
| 标准 | lv2 | 默认         |
| 详细 | lv3 | 所有能写的项都写进去 |

密度**只裁剪自动生成的部分**：你手选过的字段不受密度影响，一定会进正文。

### 3.4 手选的选项一定生效

这是 1.7.0 之后的核心原则，三个保证：

1. **手选不被预设压回去**。只有你亲手选的值才进「不许动」名单，预设里的值不再是圣旨。
2. **冲突时改搭档，不改你**。比如你手选了「牛仔夹克」，面料冲突就换面料；面料也是你手选的，就换外套类型；两个都手选，两个都保留（哪怕组合看着别扭，那是你的明确要求）。
3. **密度裁不掉手选项**。精简模式下，手选的高层级字段照样写进正文。

另外界面上有一排快捷按钮：`🎲 全部随机`（92 项全设「随机抽取」）、`📌 跟随预设`（全部回到预设），以及预设条上的「运行重抽」。

### 3.5 一致性规则

词库里的条目是独立的，随便一抽很容易抽出互相打架的组合（冬装配短裤、蹲着却说站立、自然黑发配漂后上色）。两个节点都会在合成前做一轮字段收敛，男性节点目前是 **35 条显式规则**，典型的有：

| 规则                         | 举例                                     |
| -------------------------- | -------------------------------------- |
| 外套类型 ↔ 外套材质                | 牛仔夹克不配磨砂皮                              |
| 内搭类型 ↔ 内搭面料、裤装类型 ↔ 面料 / 颜色 | 亚麻长裤不配硬挺牛仔                             |
| 鞋履 ↔ 袜装                    | 板鞋不配商务袜                                |
| 身形 ↔ 肌肉线条                  | 中年微发福不配六块腹肌                            |
| 发型长度 ↔ 造型                  | 寸头不配蓬松发量、长发不配背头、背头不配中分                 |
| 姿态 ↔ 画面瞬间                  | 蹲着不写「双脚自然平行」、坐着不写站立腿法、车内动作要配车内场景       |
| 年龄 ↔ 灰白须发                  | 20 多岁不配花白胡须                            |
| 主光来源 ↔ 光线质地                | 柔光灯板不写「清晰硬光」；柔和光源不出「落日长影」              |
| 天气 ↔ 配色                    | 阴雨不配霓虹高饱和                              |
| 时间 ↔ 调色                    | 大白天不套夜色调                               |
| 景别 ↔ 照明落点、等效焦段 ↔ 景深        | 28mm 不做极浅景深；半身构图不照亮腿部                  |
| 场景 ↔ 配套                    | 背景 / 前景 / 环境细节按地点重新匹配；匹配不上就省略，不借别的场地道具 |
| 发色 ↔ 染色方式                  | 自然黑不写「漂后上色」                            |

### 3.6 输出与分辨率

四个输出口：`中文提示词` / `推荐宽度` / `推荐高度` / `英文提示词`。中文送中文模型（如 Qwen-Image、H3），英文送 SD 系 CLIP；宽高直接接空 Latent。

分辨率相关的三项在「输出设置」里：

| 项        | 说明                             |
| -------- | ------------------------------ |
| 分辨率模式    | `原推荐尺寸` / `按总像素计算` / `固定比例总像素` |
| 目标总像素（万） | 填 100 就是 100 万像素，按所选比例换算宽高     |
| 尺寸对齐倍数   | 默认 8，宽高按此倍数取整                  |

另有 `拼接位置`（自由提示词在前 / 结构化模块在前）与 `输出排版`（按模块分段 / 连续拼接），用于把你自己的话接到结构化提示词前后。

## 四、面板与右侧即时提示词框

每个节点挂一块面板：原生控件收进折叠面板、分组分页，面板内的改动实时同步回节点控件。

右侧还有一条独立的即时提示词框（纯前端，不写进工作流文件）：

| 功能     | 说明                                  |
| ------ | ----------------------------------- |
| `⚡ 抽取` | 按当前面板设置抽一次，结果显示在框里                  |
| `↺ 复位` | 清空框内文字，回到节点输出                       |
| 运行重抽   | 打开后，每次跑工作流都按当前设置重新抽                 |
| 历史     | 本次会话抽过的提示词列表，点一下即可回填；只在内存里，不写盘      |
| 复制     | 复制框内全文                              |
| 自动重抽   | 改任意控件后约 0.3 秒自动重抽；框里的字可以直接改，改完跟着节点走 |

抽词节点的「生成后」控件统一固定在 `fixed`：跑图时不会偷偷换种子，所以**只给男性节点开「运行重抽」不会波及女性节点**。想换词只有三条路——⚡抽取、面板上的 🎲、或打开该节点的「运行重抽」，三个都是单节点的。

## 五、接线

1. 节点输出 `prompt` / `中文提示词` / `英文提示词` → 接到 **CLIP Text Encode**（或对应文本编码节点）的 `text`。
2. `推荐宽度` / `推荐高度` → 接 Empty Latent Image 的 `width` / `height`。
3. 正常 Queue Prompt 即可。

## 六、词库结构与自定义

```
data/
├─ krea2/    Krea2 卡池分卷词库（part-*.json）
├─ lr/       权威摄影 9 个 JSON（人物 / 妆发 / 服装 / 姿态 / 场景 / 光影 / 摄影）
├─ male/     男性摄影 10 个 JSON（00_share 通用层、10_theme、20_person、30_hair、
│            40/41_cloth 男装、50_pose、60_final、90_presets 预设、05_index 索引）
├─ shared/   luori.json（两个重头节点共用的摄影通用层）
└─ zimage/   整句词库、穿搭预设、风格模板、extra/（自定义分类放这里）
```

词库合计约 61 MB，全部随插件走。

**加一个分类**：把符合格式的 `.json` 丢进 `data/zimage/extra/`，重启后即多一个分类。格式说明见 `data/zimage/extra/_怎么加分类.txt`。

**改词条**：单条格式是 `{l: 标签, z: 中文片段, e: 英文片段, b: 精简片段}`，`l` 是下拉里显示的名字，`z/e/b` 是实际写进提示词的句子。改完重启即可，不需要改代码。

## 七、预设保存与写盘安全

面板上的预设条可以「保存当前组合」「载入」「删除」，存在各自的 `user_presets.json` 里，两个节点互不干扰（接口分别是 `/luori/lr_presets` 与 `/luori/male_presets`）。

写入是**原子操作**：先备份一份 `user_presets.bak.json`，再写临时文件、刷盘、最后整体替换。中途断电或磁盘满不会留下半个文件，也不会把已有的预设清空。文件损坏时读取会给出警告，而不是静默当成空表。

## 九、更新日志

### 1.8.7

- **修掉「节点自动无限向下延伸、被拉得老长」**：以前面板高度是「量自己」的——用 `root.offsetHeight` 反推节点高度，而面板元素的高度又由节点高度分配，形成 节点高 → 面板高 → 节点高 的正反馈，每 300~700ms 长一截、永不收敛。
- 现在高度改成单向流：面板内容高度（`body.scrollHeight`）→ 唯一变量 `panelH` → `computeSize/getHeight` 只读它 → `setSize(panelH + 控件偏移)`。7 个节点全部走同一套逻辑（新增 `web/layout.js`），任何环节都不再读会随节点高度变化的量。
- 定时巡检不再改高度（只保留「隐藏原生控件 / 宽度下限」兜底），高度只在内容真的变化时更新。
- 加了两道保险：面板高度硬上限 1520；以及熔断——短时间内连续同向改高度太多次就暂停自动撑高 5 秒并打一条 warn，节点照常可用。
- 顺手修掉：多个 `⚡提示词最强文生图`（Krea2）节点共用一个模块级 `panelH` / 计时器导致互相顶高、互相踩取消；`⚡提示词` 面板折叠按钮里那两行 `relayout(node, …)` 引用未定义变量、一直在抛错；节点删除后即时框的 700ms 定时器没清干净。
- 无新增依赖，工作流 JSON 格式不变。

### 1.8.6

- 启动终端不再刷本包的信息：`[SunsetMale] 预设接口就绪`、`[Hub] 路由就绪`
- 抽词节点分类网格里的「运行重抽」磁贴**删掉**：它是后端注入的隐藏 BOOLEAN 控件，被按 BOOLEAN 自动生成分类磁贴的逻辑误当成了分类。现在 `NOT_CATEGORY` 明确排除它，网格只剩 7 个真分类 + 随机模式。
- 顺带修掉一个隐患：点任意分类时 `pick()` 会遍历磁贴做互斥，以前会把「运行重抽」一起关掉；现在右侧即时框里的「运行重抽」开关不受分类选择影响。
- **功能没有删**：后端「运行重抽」控件、每次跑工作流重新抽词、种子派生都照旧，开关仍在右侧即时框底部。

### 1.8.5

- 手选的选项一定生效：预设值不再进「不许动」名单、随机抽取改为全库随机、密度不再裁掉手选字段。
- 修掉一批「写了但永远命中不了」的空转规则（背头配中分、蹲姿配站立腿法、双选互斥字段被偷改）。
- 一致性规则从 20 条扩到 35 条；「版型细节」按上装 / 裤装归位，不再出现「运动短裤，肩线与袖长超出常规」。
- 抽词节点之间互不干扰：种子「生成后」控件固定为 `fixed`，「运行重抽」改为按节点类各自派生新种子。
